# 🏃‍♂️ 乐跑健康管理系统（Campus Run Health Manager）——蓬勃悦廋

一个面向高校大学生的**智能健康管理与乐跑分析系统**，基于 Python + Streamlit 开发，融合营养学、生物医学、环境科学与运动科学，实现“运动 + 饮食 + 健康 + 环境”一体化管理。

---

## 🌟 项目亮点

- 🧠 自动热量计算（Mifflin-St Jeor 公式）
- 🏃 乐跑行为自动分级（无需手动选择活动水平）
- 🍱 饮食记录与热量追踪系统
- 📊 实时热量摄入分析与可视化
- 🍎 食物热量智能估算器
- 🩺 BMI + 睡眠质量评估系统
- 🌦 双天气源系统（腾讯 + Open-Meteo）
- ⚡ 自动容灾（API失败自动切换 + 兜底机制）
- 📱 Streamlit 响应式校园风界面

## 🌦 天气系统（核心亮点）

### ✔ 双天气源架构

| 优先级   | 数据源            | 说明      |
| ----- | -------------- | ------- |
| 🥇 主源 | 腾讯天气 API       | 高精度实时天气 |
| 🥈 备用 | Open-Meteo API | 免费稳定备用  |

---

### ✔ 容灾机制

当主 API 不可用时系统自动：

```
腾讯天气失败 → 自动切换 Open-Meteo → 仍失败则使用默认值兜底
```

保证：

* ❌ 不崩溃
* ❌ 不报错
* ✅ 永远可用 UI

---

### ✔ 支持输入

* 中文城市（北京 / 上海 / 郑州）
* 自动映射英文 API 城市名

## 📊 核心算法

### 🔥 热量计算（Mifflin-St Jeor）

```
BMR = 10 × weight + 6.25 × height - 5 × age + s
```

### 🏃 活动等级自动判定

| -- | --------- |
| 久坐 | <1次/周     |
| 轻度 | 1–3次      |
| 中度 | 3–5次      |
| 高度 | 5–7次      |
| 极高 | 7次 + 快速配速 |
